# 구버전 궤도 매트 (발사대 0도 고정)

2026-07-28 첫 수업까지 쓴 시안이다. 인쇄해서 실제로 써봤고, 그 결과 아래 두 가지가
바뀌어 새 시안으로 넘어갔다.

- 발사대가 0도 한 곳에 고정이라 모든 모둠이 같은 답을 냈다. 새 시안은 발사 원(중심에서
  95mm)에 10도 눈금을 둘러 학생이 발사각을 직접 고른다.
- 0도에만 붙어 있던 "도착 지점" 표시는 발사각이 자유로워지면서 틀린 안내가 되어
  "기준선 0°"로 바뀌었다.

새 도안은 상위 폴더의 `orbit-mat-a0.pdf`(인쇄용)와 `orbit-mat-a0.svg`(미리보기)다.
이 폴더의 파일은 참고용으로만 남긴다. **인쇄소에 넘기지 말 것.**
