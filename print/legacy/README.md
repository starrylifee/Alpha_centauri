# 구버전 궤도 매트 (발사대 0도 고정)

2026-07-28 첫 수업까지 쓴 시안이다. 인쇄해서 실제로 써봤고, 발사대가 0도 한 곳에
고정이라 모든 모둠이 같은 답을 내는 문제가 있었다.

그 뒤 시안이 두 번 바뀌었다.

1. 프록시마 둘레에 발사 원(각도 눈금 원)을 두르고 로켓을 아무 눈금에나 놓는 방식
   — 로켓이 중심별에서 출발하는 꼴이라 폐기. (git 이력 9fb332e에만 있음)
2. **현재 시안**: 발사대는 이 구버전과 같은 자리(0도 방향)에 있고, 그 둘레에
   각도기 모양 반원 각도판(0~180°, 정면 90°)을 달아 로켓 머리 방향 = 발사각을
   정한다. "도착 지점" 고정 표시는 "기준선 0°"로 바뀌었다.

새 도안은 상위 폴더의 `orbit-mat-a0.pdf`(인쇄용)와 `orbit-mat-a0.svg`(미리보기)다.
이 폴더의 파일은 참고용으로만 남긴다. **인쇄소에 넘기지 말 것.**
