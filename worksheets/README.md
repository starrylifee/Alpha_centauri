# 학생활동지

웹앱과 내용을 맞춘 학습지다. 원본은 OneDrive의 공모 서류 폴더에 그대로 있고,
여기 파일은 `build_worksheets.py`가 원본을 읽어 문장만 갈아끼워 만든 것이다.
학습지를 다시 고칠 일이 생기면 hwpx를 직접 편집하지 말고 스크립트의 치환 목록을
고친 뒤 다시 돌리는 편이 낫다. 원본이 바뀌어도 같은 수정이 그대로 얹힌다.

```
python worksheets/build_worksheets.py
```

## 웹앱과 맞춘 부분 (2026-07-28 첫 수업 이후)

| 학습지 | 예전 | 지금 |
|---|---|---|
| 미션 3 도입 | "노출 시간이 무려 24시간" | 촬영 시간 정보가 손상됐다고만 알림 |
| 미션 3 문항 | "별들은 고작 30° 선을 그렸다" | 각도 재기 → 288÷12로 촬영 시간 구하기 |
| 미션 1 표 | 자전주기 11.2일 | 12일(288시간)로 어림한다는 각주 추가 |
| 발사 계산 | 외행성 18초 / 리드 60° | 매트 안내와 같은 30초 / 리드 36° |
| 발사 기준 | "도착 지점보다 몇 도 뒤" | "내가 정한 발사각보다 몇 도 뒤" |
| 기록표 | 시도 / 힌트 수 / 성공 / 소요시간 | 시도 / 발사각 / 조난자 눈금 / 성공 |
| 접속 안내 | 태블릿 | 모둠 노트북 (준비물 표와 통일) |
| 미션 번호 | 3 다음에 다시 2 | 4로 이어짐 |

힌트 개수와 소요 시간을 기록표에서 뺀 것은 웹앱이 자동으로 세기 때문이다.

## 삽화

원본 PNG가 2816px(477dpi)여서 파일 하나가 32MB였다. 문서에 150mm 폭으로
배치되므로 300dpi에 해당하는 1772px로 줄였다. 인쇄 품질은 그대로고 12MB가 된다.

## 학생용에 대해

학생용은 문항이 들어갈 표가 원래부터 비어 있다. 문제는 웹앱 화면에 있고 종이에는
답만 적는 구조라 그대로 두었다. 종이만 보고도 풀 수 있게 하려면 그 표들을 채워야 한다.
